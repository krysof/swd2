# 《水浒传 2》C++ 重写工程

原始游戏的 2,315 个文件均已移到仓库根目录的 `game/`，本目录只放逆向记录和新写的代码。

## 当前可运行部分

- DOS MZ 可执行文件解析器（头、重定位、入口、附加数据）；
- `RSK/RS1..RS4/RAP/RRO` 的原版 64 KiB LZ/Huffman 解码器；
- 原始 `SWD2.EXE` 启动/调度状态机的等价 C++ 实现；
- DOS 资源路径规范化与资源目录统计；
- MAPA/MAPZ 世界数据库、MAP0 的 481 条地图入口/特殊事件、地图实体、DE 平面精灵、
  CHNA 事件与 Big5 对话；
- SDL 单窗口前端，以及合入同一进程的 MEO、RPG、FIG、DEMO 模块；
- 自动测试直接使用 `game/` 原始数据校验启动、地图、事件、对话和模块切换。

## 构建

```sh
cmake -S . -B build
cmake --build build
ctest --test-dir build --output-on-failure
```

查看原版可执行文件和资源清单：

```sh
./build/src/swd2_rewrite --game game --inspect
./build/src/swd2_rewrite --game game --verify-resources
./build/src/swd2_rewrite --game game --verify-maps
./build/src/swd2_rewrite --game game --verify-battles
./build/src/swd2_rewrite --extract game/MEO.RSK MEO.decoded
./build/src/swd2_rewrite --render game/MEO.RSK 0 MEO-background.ppm
./build/src/swd2_rewrite --game game --render-meo MEO-screen.ppm
./build/src/swd2_rewrite --render-map game/T2/TW-2A TW-2A.ppm
./build/src/swd2_rewrite --render-planar game/DE/DE001 17 DE001-17.ppm
./build/src/swd2_rewrite --game game \
  --save-dir portable-saves --slot 2 \
  --run-script CONFIRM,CONFIRM,CONFIRM,RIGHT,DOWN,QUIT
```
