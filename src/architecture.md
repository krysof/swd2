# 单进程、单可执行文件架构

移植版只生成一个发行程序 `swd2_rewrite`。原版通过 DOS `int 21h/4B00h` 启动的多个 EXE，不会在移植版中产生对应的进程或发行文件。

## 合并规则

| 原版程序 | 单体程序中的目标模块 |
|---|---|
| `SWD2.EXE` | `MonolithicRuntime` 状态调度器 |
| `MEO.EXE` | `MeoModule` |
| `RPG.EXE` | `RpgModule`（地图、自动实体、对话、全部 62 个事件及主要物品/演出路径） |
| `FIG.EXE` | `BattleModule` + 无平台依赖的 `BattleSession`/`BattleCommandMenu`（规则完整度优先，继续校准剧情分支和逐帧合成） |
| `DEMO.EXE` | `DemoModule`（精确 960 帧主时间线、SWORD8 尾声、音乐和揭示状态机） |
| `MAPA/MAP0/CHNA*.EXE` | 已确认这些 MZ 外壳是世界/事件数据档案，不创建进程 |
| `ITEM/ITEM2/DATE2.EXE` | 同类事件/菜单记录档案；由统一解释器读取 |
| `ORC.EXE` | 纯战斗编队/成长数据档案，由 `BattleDatabase` 读取 |
| `JGAME/JS3/MON/MEO/GA/*.EXE` | 平台输入、音频、演示组件 |
| `INSTALL.EXE` | 不进入游戏运行时；由现代打包系统代替 |

这些名称只用于对应逆向来源；实现全部链接进 `swd2_core`，最终由一个 `main()` 驱动。

## 不再保留的 DOS 机制

- 不启动子进程；模块切换是普通 C++ 虚函数调用。
- 不访问物理段 `4000:`；1350 字节状态由 `GameContext::shared_state` 管理。
- 不直接访问 VGA `A000:`、I/O 端口或中断；统一走 `PlatformBackend`。
- 不依赖当前 DOS 驱动器；资源路径由资源定位层相对 `game/` 解析。
- 不把函数指针、段地址或堆地址写进跨模块状态。

## 平台边界

`PlatformBackend` 是平台移植所需实现的唯一主要边界：

- 提交 8 位索引画面和 256 色调色板；
- 等待标准化输入动作；
- 非阻塞轮询输入并提供动画节拍；
- 提供时钟；
- 播放 RIX 音乐与 VOC 语音；
- 停止音频。

Windows、Linux、macOS、iOS、Android、WebAssembly 或主机平台可分别实现该接口，游戏规则、资源解码、地图和存档代码保持不变。

四个原版主执行文件现已全部由真实的进程内模块占据，不再有 `ExitModule`
占位。`BattleModule` 已不再按确认键直接判胜，而是用 `BattleSession` 的先制顺序、
角色/敌人行动、原版随机序列和存活状态实际打完战斗。`BattleCommandMenu` 在平台无关层
按原版四向主面板及攻击/策略子页收集能力、物品、群攻、自动、等待、逃跑、收服及敌我
目标，`BattleModule` 用 `MENU.RSK` 合成对应面板、八行滑动列表、游标和回合
生命状态；普通物品、随机战逃跑、收服和奖励捕获已接入，
捕获兽召唤后的下回合入场、双友军槽、能力/物攻 AI、随机离场和战后归还已合入；
双槽的常驻姓名卡、SP061 安装停留及满槽替换也已合入：平台无关命令菜单收集替换槽，
规则层把被替换友军写回提供新友军的背包格，呈现层按 `2f1f/111b3/5d24` 重画；
FIG 三个 MENU 媒介精灵也由 `BattleSession` 统一持有：怪物 generic 能力负责按低字节
标志召唤并退还预扣 AP，special 35h/43h/53h 负责移除，玩家/道具/捕获兽及组合技
在媒介缺失时产生同一 `missing_medium` 事件且仍按原版付费；`BattleModule` 只消费
这些平台无关事件来完成 SP049/SP061/SP002、飞行路径和常驻重画；
怪物能力事件另保留 generic/special 调用来源；前端只给 generic 执行 `25ee` 的抗性类
纯色/清洁页八步交替，special/自疗不再被误送入玩家 DS:2bbd SP/ST 时间线；
怪物五个异常计时也把设置时长和静默到期位放入事件流，由呈现层按 `2deb/2eb3`
绘制 MENU 177 与五种原图标，而不把计时规则耦合到 SDL；
规则层的怪物增益到期保留 `0b00` 首个归零即短路的优先级，事件不会错误合并多个提示；
同一事件层还把怪物目标的 `+3114` 一次性受击反应区分为物攻武器帧与首个结果数字帧，
避免前端把出手怪物整段错误画成 frame 1，并保留目录 42h 的 CD523 受击替换；
辅助选择器 `01..30` 则把处理后的 `PlayerSupportState` 作为可选目标快照附在事件上，
使其他平台前端能在原版 `58a9` 重组点同步 HP/SP/AP、上限、状态位与永久属性，而不必
重新执行规则或用单一 HP delta 猜测；呈现层按 selector 分类成单目标 `3/9` tick、

`6b` 嵌套 selector 共用一次 pose `0/4`，后者只合并同 selector 的多目标动画，确保
组合技第二段仍有独立语音/SP-ST 时间线；缺媒介事件也能和相邻嵌套段归入同一行动；
